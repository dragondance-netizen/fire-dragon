# 火龍隨拍 FIRE BEAT

香港大坑舞火龍主題的四軌網頁音樂遊戲。原創程序繪製夜景、舞龍隊與火光，無需安裝套件。

## 開啟

需要 Node.js 18 或以上。在此資料夾執行 `node server.mjs`，再打開 http://127.0.0.1:4173 。Windows 亦可雙擊 `start.cmd`。不應直接用 file:// 開啟，因瀏覽器會限制 JavaScript 模組。

## 玩法

- 四軌：D／F／J／K（或 1／2／3／4），依次是龍頭、龍身壹、龍身貳、龍尾。手機可多點觸控底部按鍵。
- 單點：音符到達金色線時按一下。
- 長按：按住至尾端通過；提早超過 100ms 鬆手算 MISS。
- 龍珠雙擊：第一下到拍，理想於 120ms 後按第二下，最遲於第一下後 240ms 按。兩次以較大誤差判定，每顆計一次分。
- PERFECT：±75ms，100 分；TOO EARLY／TOO LATE：76–180ms，50 分；MISS：0 分、扣 1 顆心，連擊歸零。
- 5 顆心用盡即 Game Over；撐至音樂完結且仍有心心即可通關。失誤會令相關龍身下墜、舞龍隊踉蹌。
- 過關評級：S ≥95%、A ≥85%、B ≥70%、C ≥50%、其餘 D；中途失敗 F。結算準確率 = 總得分／全曲最大分數。
- Enter 開始；Esc／空白鍵暫停。切換分頁或視窗自動暫停。暫停後的長按需重新按住（恢復後有 300ms 寬限）。
- 三段難度、音量、流速與 ±150ms 判定補償；同曲同難度通關最佳分數保存在本機瀏覽器。

## 關於 Lose My Mine

按要求保留《Lose My Mine》曲目題名。專案**沒有商業原曲錄音**；預設播放 Web Audio 即時合成的原創電子示範配樂（124 BPM，49 秒），並在介面明確標示。

使用「匯入音樂」選擇你可使用的 MP3、WAV、OGG、M4A 等本機檔案。檔案只在瀏覽器解碼播放，不會上傳。BPM 和首拍設定會產生對應的節奏譜（並非原曲人工譜／音訊自動節拍辨識），建議先在「演出設定」對準 BPM 與首個鼓點。支援 7 秒至 10 分鐘的音檔，格式實際可用性由瀏覽器決定。

## 技術與驗證

原生 HTML／CSS／ES modules、Canvas 2D、Web Audio；無執行期依賴與建置步驟。字型網上可用時使用 Google Fonts，離線回退系統字型。

`node --test tests/*.test.mjs` 執行計分、長按、雙擊、心心、譜面與暫停恢復測試。
